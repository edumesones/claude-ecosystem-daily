## Tendencias detectadas

- **Explosión de skills de agentes**: Docenas de repos publicando skills para Claude Code / Codex en una sola semana. El ecosistema de skills se está fragmentando — gud-framework necesita una estrategia de curación propia.
- **PPTX + IA en auge**: Varios repos apuntan a generación automática de presentaciones. La demanda de entregables visuales automatizados es real y creciente.
- **Google Workspace como gap**: Poca tracción en integraciones nativas con Google Slides/Drive. Oportunidad de diferenciación para gud-framework.
- **Gobernanza de agentes**: Microsoft y otros empiezan a publicar toolkits de compliance para IA. Señal de que el mercado corporativo exige controles antes de adoptar agentes autónomos.
