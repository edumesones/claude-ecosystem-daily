# GUD Scout - 2026-07-05

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+6 ⭐, Python) — INSTALAR — Genera PowerPoint editable real desde IA; automatiza la producción de decks de consultoría sin intervención manual.

- **[op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)** (+4 ⭐, Skill) — INSTALAR — Skill de agente para slides HTML pulidos; enchufable directamente en gud-framework como skill de presentaciones cliente.

- **[tt-a1i/archify](https://github.com/tt-a1i/archify)** (+5 ⭐, JavaScript) — INSTALAR — Skill de agente que genera diagramas de arquitectura; útil para entregables técnicos y propuestas de consultoría.

- **[infragate/capa](https://github.com/infragate/capa)** (+6 ⭐, TypeScript) — VIGILAR — Un solo `capabilities.yaml` conecta skills, tools y reglas de agente; patrón limpio para estructurar el catálogo de capacidades de gud.

- **[corsairdev/corsair](https://github.com/corsairdev/corsair)** (+6 ⭐, TypeScript) — VIGILAR — Capa de integración entre agentes; sirve como middleware para conectar los módulos de gud-framework con APIs externas (CRM, Drive, Slack).

- **[kunchenguid/firstmate](https://github.com/kunchenguid/firstmate)** (+6 ⭐, Shell) — VIGILAR — "Habla con un agente, despacha con un crew"; orquestador multi-agente ligero, patrón para pipelines de proyecto en gud.

- **[stablyai/orca](https://github.com/stablyai/orca)** (+15 ⭐, TypeScript) — VIGILAR — ADE para flotas de agentes paralelos; referencia de arquitectura para escalar gud-framework a múltiples clientes simultáneos.

- **[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)** (+13 ⭐, TypeScript) — VIGILAR — CLI que escribe y mantiene documentación de agentes automáticamente; candidato para auto-documentar los workflows de gud.

## Para tener en el radar

- **[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)** — Renderiza video desde HTML para agentes; podría automatizar video-presentaciones o demos de cliente.
- **[browser-act/skills](https://github.com/browser-act/skills)** — Skills de scraping/extracción web para agentes; útil para research de mercado automático en proyectos de consultoría.
- **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** — Skill que investiga cualquier tema en Reddit/HN/X los últimos 30 días; base para informes de tendencias de cliente.
- **[chirpz-ai/pandaprobe](https://github.com/chirpz-ai/pandaprobe)** — Trazabilidad y evaluación de agentes open source; útil para auditar la calidad de pipelines de gud en producción.
- **[VoltAgent/awesome-codex-subagents](https://github.com/VoltAgent/awesome-codex-subagents)** — Colección de 130+ subagentes especializados; banco de patrones para crear subagentes de nicho en consultoría.

## Tendencias detectadas

- **Boom de skills de presentación**: aparecen en paralelo PPT nativo (ppt-master), HTML slides (guizang-ppt-skill) y video desde HTML (hyperframes) — el mercado valida automatizar entregables visuales.
- **Multi-agente como estándar**: orca, firstmate, corsair y capa apuntan al mismo patrón: un orquestador + crews especializados + capa de integración; coincide con la dirección de gud-framework.
- **Skills componibles**: NVIDIA, browser-act y el patrón de `capabilities.yaml` (capa) señalan que el ecosistema se mueve hacia skills instalables y reutilizables, no monolitos.
