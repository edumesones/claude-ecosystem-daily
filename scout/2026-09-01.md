## Tendencias detectadas

- **Explosión de skills especializadas**: PPT, arquitectura, SEO, ciencia — el ecosistema se fragmenta en micro-skills accionables; gud debería tener su propio repositorio de skills de consultoría.
- **Memoria y contexto persistente**: Hindsight + OpenViking + codebase-memory-mcp — tres proyectos paralelos resolviendo el mismo problema; la memoria larga de clientes es el gap crítico para agentes de consultoría.
- **Infraestructura para flotas de agentes**: Orca + ArcBox — el modelo de agente único cede paso a coordinación paralela; gud-framework debería diseñarse para orquestar múltiples agentes especializados.
