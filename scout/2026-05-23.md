# GUD Scout - 2026-05-23

## Hallazgos principales

- **hugohe3/ppt-master** (+23, Python) — INSTALAR — Genera PPTX nativamente editables desde cualquier documento con IA; ideal para automatizar entregables de consultoría sin pasar por Google Slides.

- **op7418/guizang-ppt-skill** (+22, HTML) — INSTALAR — Skill de agente para generar slides HTML pulidas; se puede encadenar directo en gud-framework como paso de output de proyectos.

- **anthropics/claude-plugins-official** (+153, Python) — VIGILAR — Directorio oficial de plugins de alta calidad de Anthropic; fuente de componentes listos para integrar en el ecosistema gud.

- **multica-ai/multica** (+56, TypeScript) — VIGILAR — Plataforma open-source de managed agents que convierte código en agentes; arquitectura similar a lo que gud-framework necesita para orquestar skills de consultoría.

- **rohitg00/agentmemory** (+50, TypeScript) — VIGILAR — Memoria persistente para agentes IA basada en Knowledge Graphs; útil para que gud recuerde contexto de cliente entre sesiones.

- **ChromeDevTools/chrome-devtools-mcp** (+31, TypeScript) — VIGILAR — Servidor MCP oficial de Chrome DevTools para agentes; permite que gud-framework interactúe con portales web de clientes y CRMs.

- **teng-lin/notebooklm-py** (+25, Python) — VIGILAR — API Python no oficial + skill agentica para Google NotebookLM; puente directo al ecosistema Google Workspace para consultoría.

- **eigenpal/docx-editor** (+19, TypeScript) — VIGILAR — Editor WYSIWYG .docx open-source; para generar y editar reportes de consultoría programáticamente.

- **heygen-com/hyperframes** (+17, TypeScript) — INSPIRACION — Renderiza HTML como video, pensado para agentes; para deliverables de consultoría más ricos que un PDF estático.

- **Fission-AI/OpenSpec** (+21, TypeScript) — INSPIRACION — Desarrollo dirigido por specs para asistentes IA; patrón aplicable para estructurar flujos de propuestas y proyectos en gud.

## Tendencias detectadas

- **Explosión de skills para agentes IA**: Múltiples repos nuevos publican skills/plugins para Claude Code y otros agentes. El ecosistema se fragmenta rápido; gud-framework necesita una capa de integración de skills pronto.
- **PPTX/Slides como output de agentes**: Dos repos independientes (+ppt-master y +guizang-ppt-skill) apuntan al mismo caso de uso. La generación automatizada de presentaciones está madurando como categoría.
- **Memoria persistente para agentes**: agentmemory y otros señalan que el contexto entre sesiones se está convirtiendo en infraestructura estándar para agentes de producción.
