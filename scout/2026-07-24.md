# GUD Scout - 2026-07-24

## Hallazgos principales

- **vercel-labs/agent-skills** (+3 ⭐, JS) — INSTALAR — Colección oficial de skills para agentes Claude; se puede incorporar directamente como base para skills de gud-framework (cliente, OKR, reportes).

- **AndrewDryga/emisar** (+2 ⭐, Elixir) — INSTALAR — MCP que conecta herramientas IA a sistemas privados de forma segura; ideal para que gudframework acceda a sistemas internos de clientes sin exponer credenciales.

- **oomol-lab/open-connector** (+6 ⭐, TypeScript) — INSTALAR — Gateway de autenticación para 1000+ SaaS en una sola integración; reduce drasticamente el tiempo de onboarding de nuevas herramientas del cliente.

- **iOfficeAI/OfficeCLI** (+6 ⭐, C#) — VIGILAR — Suite Office completa vía CLI con IA nativa; podría automatizar generación de PPTX y documentos de consultoría desde pipelines.

- **different-ai/openwork** (+1 ⭐, TypeScript) — VIGILAR — Alternativa open-source a Claude Cowork; arquitectura de referencia para un portal de cliente con agentes integrados.

- **langchain-ai/openwiki** (+9 ⭐ semana, TypeScript) — VIGILAR — CLI que escribe y mantiene wikis automáticamente; perfecto para gestión de conocimiento de proyectos y entregables de consultoría.

- **withcoral/coral** (+1 ⭐, Rust) — VIGILAR — Una sola interfaz SQL sobre APIs, archivos y fuentes en vivo; simplifica pipelines de datos multi-fuente para reportes de cliente.

## Para tener en el radar

- **multica-ai/multica** — Plataforma de agentes gestionados open-source; modelo de arquitectura para orquestar múltiples agentes especializados de consultoría.
- **Thysrael/Horizon** — Radar de noticias con IA que genera digests diarios; patrón para informes automáticos de inteligencia competitiva para clientes.
- **DeusData/codebase-memory-mcp** — MCP de memoria de alta performance; patrón para mantener contexto de proyectos de clientes entre sesiones.

## Tendencias detectadas

- **Explosión de skills especializados**: aparecen colecciones de skills para dominios específicos (académico, científico, seguridad), sugiere que gud-framework debería publicar skills de consultoría propios.
- **MCPs de conectividad privada emergiendo**: emisar + open-connector + coral forman una pila de integración con sistemas internos de clientes sin fricción.
- **CLI como interfaz de productividad**: OfficeCLI, openwiki, herdr muestran que herramientas de consultoría se mueven hacia la terminal, alineado con el enfoque CLI de gud-framework.
