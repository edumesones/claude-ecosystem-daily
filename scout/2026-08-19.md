# GUD Scout - 2026-08-19

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+2 ⭐, Python) — INSTALAR — Genera PowerPoint nativo desde documentos o temas con IA; ideal para automatizar entregas de consultoría sin tener que abrir PowerPoint.

- **[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)** (+3 ⭐, HTML) — INSTALAR — 29 tipos de diagramas editoriales para Claude Code; acelera la producción de material visual para propuestas y reportes.

- **[larashero3-dotcom/lieflat-charts](https://github.com/larashero3-dotcom/lieflat-charts)** (+1 ⭐) — INSTALAR — Skill de visualización de datos para agentes IA; convierte datos crudos en charts listos para presentaciones de cliente.

- **[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)** (+2 ⭐, JavaScript) — VIGILAR — Skills de marketing con soporte CRM para Claude Code; puede extenderse a gestión de pipeline de clientes en gud-framework.

- **[letta-ai/letta-code](https://github.com/letta-ai/letta-code)** (+1 ⭐, TypeScript) — VIGILAR — Agentes stateful con memoria persistente tipo "persona"; útil para mantener contexto de cliente entre sesiones de consultoría.

- **[docling-project/docling-agent](https://github.com/docling-project/docling-agent)** (+1 ⭐, Python) — VIGILAR — Agente que lee, escribe y edita documentos en múltiples formatos; integrable en pipelines de generación de reportes y entregables.

- **[stablyai/orca](https://github.com/stablyai/orca)** (+3 ⭐, TypeScript) — VIGILAR — ADE para orquestar flotas de agentes paralelos; potencial para automatizar múltiples análisis de clientes simultáneamente.

## Para tener en el radar

- **[zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides)** — Alternativa web para crear slides desde código; interesante si se quiere salir del ecosistema Office.

- **[akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory)** — Memoria de largo plazo para agentes CLI en Rust; complementa a letta-code para persistencia de contexto.

- **[internet-court/internet-court-skill](https://github.com/internet-court/internet-court-skill)** — Capa de confianza para commerce agente-a-agente; relevante si gud-framework escala a mercados multi-agente.

## Tendencias detectadas

- **Skills de presentación en auge**: ppt-master, frontend-slides y diagram-design aparecen juntos — hay demanda de generar material visual directamente desde agentes IA.
- **Persistencia y memoria de agentes**: letta-code y ai-memory apuntan a que los agentes necesitan "recordar" entre sesiones, clave para CRM automatizado.
- **Orquestación paralela como estándar**: orca y la proliferación de workspaces multi-agente (holaOS, Kun) indican que la flota de agentes es el modelo dominante en 2026.
