# GUD Scout - 2026-08-20

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+3, Python) — INSTALAR — IA convierte documentos o temas en PowerPoint nativo; ideal para automatizar entregables de consultoría.

- **[op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)** (+2, JavaScript) — INSTALAR — Skill de Claude que genera slides HTML pulidos desde agente; se integra directamente al workflow de gud.

- **[chuspeeism/dashi-ppt-skill](https://github.com/chuspeeism/dashi-ppt-skill)** (+2, JavaScript) — INSTALAR — Alternativa a guizang: slides editables en el browser generadas por agente IA.

- **[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)** (+10, HTML) — INSTALAR — 29 tipos de diagramas editoriales para Claude Code; cubre mapas de proceso, flujos y arquitecturas de consultoría.

- **[volcengine/OpenViking](https://github.com/volcengine/OpenViking)** (+7, Python) — VIGILAR — Base de contexto auto-evolutiva para agentes; útil como capa de memoria persistente entre sesiones de cliente en gud.

- **[virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)** (+5, Python) — VIGILAR — Convierte cualquier PDF técnico en un skill de Claude; automatiza el onboarding de conocimiento sectorial o de cliente.

- **[stablyai/orca](https://github.com/stablyai/orca)** (+6, TypeScript) — VIGILAR — ADE para flotas de agentes paralelos; podría orquestar múltiples flujos simultáneos de gud (análisis + deck + CRM).

- **[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)** (+3, JavaScript) — VIGILAR — Skills de marketing para Claude con patrones de CRM; aprovechable para automatizar propuestas y seguimiento comercial.

- **[yizhiyanhua-ai/fireworks-tech-graph](https://github.com/yizhiyanhua-ai/fireworks-tech-graph)** (+2, Python) — VIGILAR — Genera diagramas técnicos SVG/PNG de calidad producción; complementa ppt-master para deliverables visuales.

- **[diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute)** (+4, TypeScript) — VIGILAR — Gateway IA unificado (MIT): un endpoint para todos los LLMs; simplifica gestión de proveedores y costes en gud.

## Para tener en el radar

- **[openai/symphony](https://github.com/openai/symphony)** — Convierte trabajo en proyectos autónomos aislados; modelo interesante de gestión de proyectos para replicar en gud.
- **[docling-project/docling-graph](https://github.com/docling-project/docling-graph)** — Parsing de documentos a grafos; para análisis automático de documentos de cliente (RFPs, contratos, informes).
- **[microsoft/agent-governance-toolkit](https://github.com/microsoft/agent-governance-toolkit)** — Toolkit de governance para agentes IA; relevante si gud escala en clientes enterprise con requisitos de auditoría.

## Tendencias detectadas

- **Explosión de skills de presentaciones**: tres repos independientes de generación de PPTX/slides vía agente en un solo día; el mercado está validando este caso de uso masivamente.
- **Capas de contexto persistente para agentes**: OpenViking + book-to-skill apuntan a que el siguiente paso es que los agentes "aprendan" el contexto de cada cliente y lo mantengan entre sesiones.
- **Orquestación multi-agente mainstream**: Orca, OmniRoute y Symphony sugieren que los flujos de varios agentes en paralelo ya no son experimentales — son el estándar emergente.
