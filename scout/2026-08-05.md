# GUD Scout - 2026-08-05

## Hallazgos principales

- **iOfficeAI/OfficeCLI** (3⭐, C#) — INSTALAR — Suite Office completa orientada a agentes IA; permite automatizar documentos, presentaciones y hojas de cálculo desde CLI, ideal para generar entregables de consultoría.

- **firecrawl/pdf-inspector** (4⭐, Rust) — INSTALAR — Inspector de PDFs de alta velocidad; útil para procesar propuestas, contratos y reportes de clientes antes de pasarlos a un agente.

- **virgiliojr94/book-to-skill** (3⭐, Python) — INSTALAR — Convierte cualquier PDF técnico en un skill de Claude Code; pipeline directo para convertir metodologías de consultoría en habilidades reutilizables.

- **yc-software/qm** (6⭐, TypeScript) — VIGILAR — Harness multi-agente para trabajo colaborativo; arquetipo para coordinar agentes especializados (research, redacción, delivery) en flujos de consultoría.

- **multica-ai/multica** (2⭐, Go) — VIGILAR — Plataforma open-source de agentes gestionados; permite desplegar workflows de agentes como servicios, encaja con la arquitectura de automatización de GUD.

- **tt-a1i/archify** (2⭐, HTML) — VIGILAR — Skill de agente para generar diagramas de arquitectura verificables y visualmente atractivos; útil para slides y entregables técnicos a clientes.

- **AeternaLabsHQ/pullmd** (1⭐, —) — VIGILAR — Servicio self-hosted que convierte URLs y archivos a Markdown para agentes; pieza clave para pipelines de ingesta de documentos de clientes.

## Para tener en el radar

- **shaharia-lab/slackcli** (1⭐, TypeScript) — CLI para Slack; podría automatizar comunicaciones y notificaciones a clientes desde workflows de agentes.
- **Gentleman-Programming/engram** (1⭐, Go) — Memoria persistente para agentes; relevante para mantener contexto entre sesiones de consultoría.
- **TencentCloud/TencentDB-Agent-Memory** (1⭐, TypeScript) — Hub de memoria a nivel equipo para agentes; interesante para compartir contexto entre múltiples consultores.

## Tendencias detectadas

- **Skills como unidad de distribución**: múltiples repos empaquetan capacidades especializadas (marketing, arquitectura, libros) como skills de Claude; GUD debería publicar sus propias skills de consultoría.
- **Harnesses multi-agente emergentes**: qm y multica representan una tendencia hacia coordinar flotas de agentes para trabajo real, no solo tareas individuales.
- **Memoria de agentes**: engram, TencentDB-Agent-Memory y mnemosyne apuntan a que la persistencia de contexto es el próximo cuello de botella a resolver.
