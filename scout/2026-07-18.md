# GUD Scout - 2026-07-18

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+2, Python) — INSTALAR — Convierte documentos o temas en PowerPoint nativo con IA; ideal para automatizar entregas de consultoría.
- **[FB208/OpenBidKit_Yibiao](https://github.com/FB208/OpenBidKit_Yibiao)** (+5, JavaScript) — INSTALAR — Herramienta IA open-source para redacción de propuestas y licitaciones con base de conocimiento integrada; directamente aplicable a generación de propuestas de consultoría.
- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (+17 semanal, C#) — INSTALAR — Suite Office CLI para agentes IA; automatiza Word/Excel/PowerPoint desde la terminal, sólido y con tracción sostenida esta semana.
- **[1weiho/open-slide](https://github.com/1weiho/open-slide)** (+2, TypeScript) — VIGILAR — Framework de slides diseñado específicamente para agentes; permite generar presentaciones de forma programática.
- **[oomol-lab/open-connector](https://github.com/oomol-lab/open-connector)** (+3, TypeScript) — VIGILAR — Gateway de autenticación open-source para 1000+ SaaS incluyendo Google Workspace; reemplaza integraciones manuales con Drive/Sheets.
- **[microsoft/flint-chart](https://github.com/microsoft/flint-chart)** (+5, TypeScript) — VIGILAR — Lenguaje de visualización que permite a agentes crear gráficos y reportes de datos; útil para dashboards de clientes.
- **[stablyai/orca](https://github.com/stablyai/orca)** (+11, TypeScript) — VIGILAR — ADE para flotas de agentes paralelos; referencia de arquitectura para orquestar tareas de consultoría multi-agente.
- **[multica-ai/multica](https://github.com/multica-ai/multica)** (+3, Go) — VIGILAR — Plataforma open-source de agentes gestionados; base para automatizar flujos complejos de entrega de consultoría.

## Para tener en el radar

- **[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)** — CLI que escribe y mantiene documentación de agentes; útil para mantener playbooks de gud-framework actualizados.
- **[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)** — Colección curada de 1000+ skills de agentes; biblioteca de referencia para expandir capacidades del framework.
- **[team-reflect/reflect-open](https://github.com/team-reflect/reflect-open)** — Agente local-first con IA para gestión de notas; inspiración para portales de cliente con contexto persistente.

## Tendencias detectadas

- **Explosión de skills para agentes**: tres repos de "skills" aparecieron simultáneamente (emilkowalski, ibelick, VoltAgent) — el ecosistema está convergiendo hacia skills empaquetadas como unidad de extensión.
- **PPTX/presentaciones con IA**: dos herramientas de generación de presentaciones en un mismo ciclo (ppt-master, open-slide) — alta demanda de automatización de entregables visuales.
- **Gateways SaaS open-source**: open-connector y OmniRoute señalan un movimiento hacia alternativas open-source a Zapier/Make para integraciones de consultoría.
