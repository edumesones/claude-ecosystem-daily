# GUD Scout - 2026-07-09

## Hallazgos principales

- **NomaDamas/slides-grab** (2⭐, TypeScript) — INSTALAR — Harness + editor + linter para generar slides directamente desde agentes; clave para automatizar entregables de consultoría en presentaciones.

- **iOfficeAI/OfficeCLI** (12⭐, C#) — VIGILAR — Suite ofimática CLI orientada a IA; permite manipular documentos Office desde pipelines automatizados sin interfaz gráfica.

- **oomol-lab/open-connector** (4⭐, TypeScript) — INSTALAR — Gateway de autenticación que conecta 1000+ productos SaaS; acelera integraciones con Google Workspace, CRMs y herramientas de proyecto en gud-framework.

- **VoltAgent/awesome-agent-skills** (2⭐) — INSTALAR — Colección curada de 1000+ skills para agentes; punto de partida para ampliar capacidades de los agentes de consultoría sin desarrollar desde cero.

- **MadsLorentzen/ai-job-search** (39⭐, TypeScript) — INSPIRACION — Framework de automatización de procesos complejos sobre Claude; patrón directo para modelar flujos de consultoría (intake → análisis → entregable).

## Para tener en el radar

- **langchain-ai/openwiki** (8⭐, TypeScript) — CLI que escribe y mantiene wikis de workflows; útil para documentar y versionar procesos de consultoría como agentes ejecutables.

- **volcengine/OpenViking** (2⭐, Python) — Base de datos de contexto auto-evolutiva para agentes; permite a gud-framework recordar contexto de proyectos entre sesiones.

- **heygen-com/hyperframes** (2⭐, TypeScript) — Convierte HTML en video generado por agentes; posible canal de entrega para reportes dinámicos a clientes.

- **777genius/agent-teams-ai** (1⭐, TypeScript) — Orquestación de equipos de agentes especializados; modelo para estructurar el equipo consultor virtual de gud-framework.

- **microsoft/SkillOpt** (2⭐, Python) — Optimizador de skills reutilizables en espacio de texto; inspiración para mejorar la calidad de skills propios de gud sin aumentar tokens.

## Tendencias detectadas

- Proliferación de **skills y colecciones de skills** para Claude Code: el ecosistema se está modularizando rápido; gud debería publicar sus propios skills antes de que el mercado sature.
- **Generación de contenido visual desde agentes** (slides, video, HTML→render) es el área más activa para entregables; NomaDamas/slides-grab es la opción más madura hoy.
- **Memoria y contexto persistente** para agentes (Beads, OpenViking, TencentDB-Agent-Memory) indica que el problema de sesiones sin estado es prioritario en la comunidad.
