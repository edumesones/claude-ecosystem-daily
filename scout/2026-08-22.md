# GUD Scout - 2026-08-22

## Hallazgos principales

- **hugohe3/ppt-master** (+3, Python) — INSTALAR — Convierte documentos o temas en PPTX nativos con IA; ideal para automatizar entregables de consultoría al cliente.
- **chuspeeism/dashi-ppt-skill** (+2, JavaScript) — INSTALAR — Skill de agente que genera presentaciones editables en el navegador; plug-and-play con Claude Code para flujos de propuestas.
- **docling-project/docling-graph** (+4, Python) — INSTALAR — Transforma documentos no estructurados (PDF, Word) en grafos de conocimiento validados; perfecto para ingerir contratos y briefings de clientes.
- **vectorize-io/hindsight** (+3, Python) — VIGILAR — Memoria de agente que aprende con el tiempo; permite recordar contexto de proyectos y clientes entre sesiones.
- **larashero3-dotcom/lieflat-charts** (+2) — VIGILAR — Skill de visualización de datos para agentes; convierte tablas en gráficas listas para insertar en reportes de consultoría.
- **cathrynlavery/diagram-design** (+4, HTML) — VIGILAR — 29 tipos de diagramas editoriales para Claude Code; acelera la creación de slides de arquitectura y proceso.
- **stablyai/orca** (+2, TypeScript) — VIGILAR — Entorno para orquestar flotas de agentes paralelos; útil para ejecutar múltiples análisis de consultoría simultáneamente.

## Para tener en el radar

- **tt-a1i/archify** (+3, HTML) — Skill para diagramas de arquitectura verificables; útil para propuestas técnicas a clientes.
- **volcengine/OpenViking** (+3, Python) — Base de datos de contexto auto-evolutiva para agentes; patrón interesante para gestionar conocimiento de proyectos.
- **henryqin1997/statem** (+4 semanal, Python) — Runbook CLI para ejecuciones largas de agentes; modelo replicable para pipelines de automatización de informes.

## Tendencias detectadas

- **Skills de presentación en auge**: dos repos independientes de generación de PPTX/slides surgieron en 24h, señal de demanda real en flujos de trabajo con IA.
- **Memoria de agente como infraestructura**: hindsight y ai-memory lideran en crecimiento sostenido; la consultoría necesita agentes con contexto persistente por cliente/proyecto.
- **Procesamiento de documentos unstructurados**: docling-graph y patrones similares apuntan a un ecosistema maduro para ingerir contratos, briefings y reportes como datos.
