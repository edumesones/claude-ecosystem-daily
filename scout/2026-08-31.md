# GUD Scout - 2026-08-31

## Hallazgos principales

- **[googleworkspace/cli](https://github.com/googleworkspace/cli)** (+983 esta semana, Rust) — INSTALAR — CLI unificada para todo Google Workspace desde terminal; automatiza Docs, Drive, Sheets y Slides sin pasar por el navegador, ideal para pipelines de entrega de consultoría.

- **[tt-a1i/archify](https://github.com/tt-a1i/archify)** (+41, HTML) — INSTALAR — Skill de agente que genera diagramas de arquitectura verificables y visualmente atractivos; perfecto para entregar presentaciones técnicas a clientes sin esfuerzo manual.

- **[sapientinc/PRAXIST](https://github.com/sapientinc/PRAXIST)** (+11, Python) — VIGILAR — Sistema de investigación autónomo con salidas medibles y computables; puede alimentar la fase de discovery de proyectos de consultoría de forma automatizada.

- **[paperclipai/paperclip](https://github.com/paperclipai/paperclip)** (+3053 esta semana, TypeScript) — VIGILAR — Orquestador open-source para workflows sin intervención humana; arquitectura cercana a lo que gud-framework necesita para automatizar entregas end-to-end.

- **[Agents365-ai/drawio-skill](https://github.com/Agents365-ai/drawio-skill)** (+3, Python) — INSTALAR — Genera diagramas draw.io desde lenguaje natural vía Claude; útil para producir entregables visuales (procesos, org charts) directamente desde prompts del consultor.

- **[virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)** (+4, Python) — VIGILAR — Convierte cualquier PDF técnico en una skill de Claude Code; permite empaquetar metodologías propietarias de GUD como skills reutilizables.

- **[volcengine/OpenViking](https://github.com/volcengine/OpenViking)** (+6, Python) — VIGILAR — Base de datos de contexto auto-evolutiva para agentes IA; resuelve el problema de memoria persistente entre sesiones de agentes de consultoría.

- **[workweave/router](https://github.com/workweave/router)** (+9, Go) — VIGILAR — Router de modelos para sistemas agénticos que selecciona el LLM óptimo por tarea; reduce costos en pipelines con múltiples pasos de automatización.

## Tendencias detectadas

- **Skills como unidad de entrega**: el ecosistema converge hacia empaquetar capacidades de agente como skills instalables (book-to-skill, drawio-skill, archify); GUD puede adoptar este patrón para distribuir sus automatizaciones.
- **Google Workspace como backend**: googleworkspace/cli y notebooklm-py señalan que la integración nativa con el stack de Google se está formalizando vía herramientas CLI/API.
- **Orquestación sin humanos**: paperclipai y workweave/router muestran madurez creciente en workflows completamente autónomos, alineados con la visión de consultoría automatizada.
