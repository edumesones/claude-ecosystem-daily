# GUD Scout - 2026-07-19

## Hallazgos principales

- **stablyai/orca** (3⭐, TypeScript) — VIGILAR — ADE (entorno de desarrollo de agentes) para flotas de agentes paralelos; arquitectura directamente aplicable a orquestar múltiples consultores IA en gud-framework.
- **agentlas-ai/Agentlas-OS** (1⭐, Python) — VIGILAR — "OS" para mantener agentes especialistas en un hub y activarlos bajo demanda; modelo de activación que encaja con el diseño de skills especializadas de gud.
- **iOfficeAI/OfficeCLI** (3⭐, C#) — VIGILAR — Suite Office completa vía CLI; automatización de Word/Excel/PPT desde terminal sin GUI, útil para generar entregables de consultoría programáticamente.
- **ogulcancelik/herdr** (4⭐, Rust) — VIGILAR — Multiplexor de agentes en terminal; permite enrutar tareas a distintos agentes desde un solo punto, relevante para pipeline multi-agente de gud.
- **jnMetaCode/agency-agents-zh** (2⭐, Shell) — INSPIRACION — 266 roles de experto IA plug-and-play para Claude Code/Hermes; banco de personas listas para distintos dominios de consultoría.
- **deepcoldy/botmux** (1⭐, TypeScript) — VIGILAR — Bridge entre plataformas de mensajería (Slack, Teams) y CLIs de IA; canal directo para que clientes interactúen con gud desde su herramienta de comunicación habitual.
- **vercel-labs/agent-browser** (1⭐) — VIGILAR — CLI de automatización de browser para agentes; permite a gud-framework recopilar datos de portales de cliente o CRMs web sin API pública.
- **diegosouzapw/OmniRoute** (3⭐, TypeScript) — VIGILAR — Gateway gratuito de IA con un solo endpoint para múltiples proveedores; reduce fricción al cambiar de modelo en pipelines de consultoría.
- **Tencent-Hunyuan/HunyuanOCR** (1⭐, Python) — VIGILAR — OCR de alta precisión de Tencent; útil para ingerir contratos y documentos de clientes en PDF al pipeline de datos de gud.

## Para tener en el radar

- **AI-Builder-Club/skills** — Skills de harness + loop engineer; referencia para ampliar el catálogo de skills propias de gud-framework.
- **wdcpclover/ai4paper** (HTML) — Traducción de PDFs sin configuración con 240M fuentes; potencial para internacionalizar entregables de consultoría.
- **anthropics/cwc-workshops** (TypeScript) — Workshops oficiales de Anthropic; material de referencia para mantener gud-framework alineado con las últimas prácticas de Claude.

## Tendencias detectadas

- **Flotas de agentes paralelos**: orca y Agentlas-OS apuntan a que la industria se mueve hacia orquestar docenas de agentes especializados en vez de uno generalista; gud debería preparar su capa de routing.
- **CLI como superficie de integración**: herdr, OfficeCLI, OmniRoute y botmux son todos CLI-first; el patrón confirma que automatización de consultoría vía terminal es el camino de menor fricción.
- **Bridge IM → IA**: botmux muestra demanda creciente de conectar Slack/Teams directamente con agentes; oportunidad para que clientes de gud usen su herramienta actual sin portal nuevo.
