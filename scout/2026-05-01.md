# GUD Scout - 2026-05-01

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (41⭐, Python) — INSTALAR — Genera PPTX nativas y editables desde cualquier documento usando IA. Directo al flujo de deliverables de consultoría, sin pasar por Canva ni Google Slides manualmente.

- **[openai/symphony](https://github.com/openai/symphony)** (95⭐, Elixir) — VIGILAR — Convierte trabajo de proyectos en agentes autónomos aislados. Arquitectura relevante para descomponer engagements de consultoría en tareas paralelas.

- **[mattpocock/skills](https://github.com/mattpocock/skills)** (611⭐, Shell) — VIGILAR — Directorio personal de skills para agentes IA con tracción viral. El patrón "skills como unidades reutilizables" es exactamente lo que necesita gud-framework para escalar capacidades.

- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** (52⭐, Shell) — VIGILAR — Skills de nivel producción para agentes de código. Referencia de cómo empaquetar capacidades técnicas de alto valor para automatizar entregables.

- **[ComposioHQ/awesome-codex-skills](https://github.com/ComposioHQ/awesome-codex-skills)** (46⭐, Python) — VIGILAR — Lista curada de skills prácticas para automatización con Codex. Banco de ideas para skills de consultoría (análisis, reportes, integraciones).

- **[multica-ai/multica](https://github.com/multica-ai/multica)** (29⭐, TypeScript) — VIGILAR — Plataforma open-source de agentes gestionados. Alternativa a construir la capa de orquestación desde cero en gud-framework.

- **[browser-use/browser-harness](https://github.com/browser-use/browser-harness)** (31⭐, Python) — VIGILAR — Harness auto-reparable que habilita agentes para navegar la web. Útil para scraping de datos de cliente y llenado de formularios en portales externos.

- **[rtk-ai/rtk](https://github.com/rtk-ai/rtk)** (34⭐, Rust) — VIGILAR — Proxy CLI que reduce 60% el consumo de tokens LLM. Directamente aplicable para bajar costos operativos en pipelines de gud-framework.

- **[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)** (35⭐, TypeScript) — INSPIRACION — Escribe HTML, renderiza video, diseñado para agentes. Abre la posibilidad de generar presentaciones en video de resultados de consultoría.

- **[santifer/career-ops](https://github.com/santifer/career-ops)** (19⭐) — INSPIRACION — Sistema de operaciones completo construido sobre Claude Code. Patrón de arquitectura reutilizable para gud-framework (pipelines declarativos + Claude como motor).

## Para tener en el radar

- **[sandeco/reversa](https://github.com/sandeco/reversa)** (JavaScript) — Transforma sistemas legacy en especificaciones ejecutables; útil para documentar y reingeniería de procesos de clientes.
- **[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)** — Skills de gestión del conocimiento para agentes; base para un CRM ligero sobre Obsidian.
- **[mattpocock/sandcastle](https://github.com/mattpocock/sandcastle)** (38⭐, TypeScript) — Orquestación de agentes en sandbox con TypeScript; referencia para el runner de tareas de gud-framework.
- **[stripe/link-cli](https://github.com/stripe/link-cli)** (21⭐, TypeScript) — Permite que agentes ejecuten pagos directamente; abre la puerta a facturación automática en flujos de consultoría.

## Tendencias detectadas

- **"Skills" como unidad modular dominante**: mattpocock, addyosmani, ComposioHQ y decenas más convergen en empaquetar capacidades como skills instalables. El ecosistema se fragmenta en miles de mini-capacidades.
- **Orquestación de agentes paralelos madura**: symphony, sandcastle, multica y multica proponen agentes aislados por tarea. La consultoría se presta naturalmente a este patrón (análisis ≠ redacción ≠ presentación).
- **Optimización de costos LLM como preocupación real**: rtk, CLIProxyAPI y variantes apuntan a que los costos ya duelen en producción. gud-framework debería incorporar una capa de caché/optimización.
