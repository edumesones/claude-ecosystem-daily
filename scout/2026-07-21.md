# GUD Scout - 2026-07-21

## Hallazgos principales

- **iflytek/astron-rpa** (⭐4, Java) — INSTALAR — Suite RPA lista para agentes IA con automatizaciones out-of-the-box; ideal para automatizar flujos repetitivos de consultoría (recolección de datos, generación de reportes).

- **iflytek/skillhub** (⭐2, Java) — VIGILAR — Registro de skills de agentes auto-hospedado y open-source; permitiría a gud-framework publicar y distribuir sus propias skills de consultoría de forma centralizada.

- **initializ/forge** (⭐1, Go) — INSTALAR — Runtime open-source para el Agent SDK de Anthropic; base técnica directa para correr los agentes gud en producción sin lock-in.

- **coreyhaines31/marketingskills** (⭐2, JavaScript) — VIGILAR — Colección de skills de marketing para Claude Code y agentes IA; inspira un módulo de skills de consultoría (propuestas, diagnósticos, OKRs) con la misma arquitectura.

- **langchain-ai/openwiki** (⭐2, TypeScript) — VIGILAR — CLI que escribe y mantiene wikis de agentes automáticamente; útil para documentar el conocimiento de proyectos de consultoría generado por IA.

- **corsairdev/corsair** (⭐1, TypeScript) — VIGILAR — Capa de integración para agentes; podría servir como middleware entre gud-framework y sistemas externos (CRM, Drive, Slides).

- **Yeachan-Heo/oh-my-claudecode** (⭐1, Shell) — VIGILAR — Orquestación multi-agente teams-first para Claude Code; patrón relevante para coordinar agentes especializados dentro de gud (estrategia, diseño, entrega).

## Para tener en el radar

- **dontbesilent2025/dbskill** — Skills de diagnóstico de negocio (商业诊断); podría adaptarse para verticales de consultoría de gud.
- **ogulcancelik/herdr** — Multiplexor de agentes en la terminal; inspiración para routing de tareas entre agentes especializados.
- **kunchenguid/firstmate** — "Habla con un agente, entrega con un equipo"; arquitectura de coordinación multi-agente con interfaz simple.

## Tendencias detectadas

- **Explosión de Skills para Claude Code**: múltiples repos (emilkowalski/skills, ibelick/ui-skills, garden-skills, marketingskills) sugieren que el ecosistema de skills es el nuevo vector de extensibilidad — gud debería publicar sus propias skills.
- **Registros de skills auto-hospedados**: iflytek/skillhub apunta a una tendencia de organizations que quieren controlar su propio catálogo de skills en lugar de depender de registros públicos.
- **RPA + Agentes convergiendo**: astron-rpa y similares muestran que la automatización de procesos tradicional se está fusionando con agentes LLM, creando oportunidades para consulting automation end-to-end.
