## Hallazgos principales

- **[google/skills](https://github.com/google/skills)** (+33, Python) — INSTALAR — Skills oficiales de Google para agentes: Google Workspace, Slides y Drive directamente en Claude Code; elimina la integración manual con G Suite.

- **[trycompai/crm](https://github.com/trycompai/crm)** (+16, TypeScript) — VIGILAR — CRM open source agentic-first: gestión de clientes y proyectos con agentes IA nativos, ideal como base para el portal de clientes de gud-framework.

- **[alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills)** (+18, Python) — INSTALAR — Colección de 345 skills para Claude Code; repositorio listo para extraer skills de productividad y automatización aplicables a flujos de consultoría.

- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (+12, C#) — VIGILAR — Suite ofimática CLI para agentes IA: puede generar PPTX, DOCX y reportes de Office desde la terminal sin abrir el escritorio, clave para entrega de deliverables.

- **[different-ai/openwork](https://github.com/different-ai/openwork)** (+13, TypeScript) — VIGILAR — Alternativa open source a Claude Cowork: gestión de tareas y work tracking para equipos de agentes; arquitectura directamente reutilizable en gud-framework.

- **[agentplugins/agent-plugins-spec](https://github.com/agentplugins/agent-plugins-spec)** (+20) — VIGILAR — Especificación estándar v1.0 para plugins de agentes; adoptar este formato garantiza interoperabilidad futura de los plugins de gud con el ecosistema.

- **[virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)** (+52, Python) — INSTALAR — Convierte PDFs de libros técnicos en skills de Claude Code automáticamente; perfecto para onboardear metodologías de consultoría existentes al sistema.

- **[firecrawl/pdf-inspector](https://github.com/firecrawl/pdf-inspector)** (+18, Rust) — VIGILAR — Inspector de PDF de alto rendimiento; útil para procesar y extraer datos de propuestas, contratos y reportes de clientes en el pipeline de gud.
