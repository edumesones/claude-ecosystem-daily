# GUD Scout - 2026-07-20

## Hallazgos principales

- **[iflytek/astron-rpa](https://github.com/iflytek/astron-rpa)** (+2, Python) — INSTALAR — Suite RPA lista para agentes IA; automatiza flujos repetitivos de consultoria como extraccion de datos, llenado de formularios y reportes.

- **[diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute)** (+6, TypeScript) — INSTALAR — Gateway gratuito de IA con un solo endpoint; simplifica conectar multiples modelos al gud-framework sin reescribir el pipeline de integraciones.

- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (+22 semanal, C#) — INSTALAR — Suite Office completa desde CLI; candidato directo para el modulo de generacion de PPTX/Word/Excel desde agentes.

- **[iflytek/skillhub](https://github.com/iflytek/skillhub)** (+6, Java) — VIGILAR — Registro auto-hospedado de skills de agentes; puede ser el catalogo central de habilidades del gud-framework.

- **[stablyai/orca](https://github.com/stablyai/orca)** (+6, TypeScript) — VIGILAR — Entorno de desarrollo para flotas de agentes paralelos; patron clave para orquestar multiples tareas de consultoria en simultaneo.

- **[oomol-lab/open-connector](https://github.com/oomol-lab/open-connector)** (+7 semanal, TypeScript) — VIGILAR — Gateway de auth que conecta 1000+ SaaS; capa de integracion lista para conectar herramientas del cliente (Drive, Notion, CRM).

- **[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)** (+10 semanal, TypeScript) — VIGILAR — CLI que escribe y mantiene documentacion de agentes; util para generar entregables de consultoria automaticamente desde el pipeline.

- **[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)** (+7 semanal) — VIGILAR — Coleccion de 1000+ skills de agentes curadas; referencia directa para ampliar el repertorio del gud-framework.

## Para tener en el radar

- **[ogulcancelik/herdr](https://github.com/ogulcancelik/herdr)** (+23 semanal, Rust) — Multiplexor de agentes en terminal; puede ser orquestador ligero de pipelines de consultoria.
- **[yizhiyanhua-ai/fireworks-tech-graph](https://github.com/yizhiyanhua-ai/fireworks-tech-graph)** (+4, Python) — Genera diagramas tecnicos SVG/PNG de produccion; util para entregables visuales en presentaciones.
- **[alibaba/page-agent](https://github.com/alibaba/page-agent)** (+2, TypeScript) — Agente GUI en-pagina; potencial para automatizar portales web de clientes sin API.
- **[getpaseo/paseo](https://github.com/getpaseo/paseo)** (+5, TypeScript) — Orquestacion de coding agents desde desktop; patron relevante para supervisar pipelines multi-agente.

## Tendencias detectadas

- Explosion de registros/catalogos de skills (skillhub, VoltAgent/awesome-agent-skills, cloudflare/skills): el ecosistema se esta estandarizando en torno a "skill marketplaces".
- Gateways AI unificados proliferan (OmniRoute, open-connector): la capa de integracion se vuelve commodity.
- Orquestacion multi-agente madura: orca, herdr, paseo y firstmate muestran patrones distintos — flota paralela, multiplexor, desktop y crew-ship.
