# GUD Scout - 2026-06-05

## Hallazgos principales

- **iOfficeAI/OfficeCLI** (+10, C#) — INSTALAR — CLI de línea de comandos para Office; permite generar y manipular PPTX/Word/Excel desde agentes sin interfaz gráfica, ideal para automatizar entregables de consultoría.

- **addyosmani/agent-skills** (+6, Shell) — INSTALAR — Skills de producción para agentes de código; patrón directo para construir y empaquetar los skills de gud-framework con calidad enterprise.

- **rtk-ai/rtk** (+16, Rust) — INSTALAR — Proxy CLI que reduce el consumo de tokens LLM un 60%; crítico para bajar costos operativos en pipelines de consultoría de alto volumen.

- **unicity-astrid/astrid** (+199, Rust) — VIGILAR — Sistema operativo para agentes IA; define la arquitectura base de orquestación multi-agente que gud-framework necesitará escalar.

- **multica-ai/multica** (+8, TypeScript) — VIGILAR — Plataforma open-source de agentes gestionados; convierte agentes de código en workflows automatizados, muy alineado con el modelo de consultoría como servicio.

- **heygen-com/hyperframes** (+11, TypeScript) — VIGILAR — Escribe HTML y renderiza video desde agentes; puente potente para convertir reportes HTML en presentaciones o demos de cliente.

- **Lum1104/Understand-Anything** (+27, TypeScript) — VIGILAR — Convierte cualquier dato en gráficos explicativos; útil para generar visualizaciones automáticas en reportes de diagnóstico.

- **getpaseo/paseo** (+12, TypeScript) — VIGILAR — Orquesta agentes de código remotamente desde el móvil; permite supervisar pipelines de consultoría en ejecución sin estar en el escritorio.

- **rohitg00/agentmemory** (+7, TypeScript) — VIGILAR — Memoria persistente para agentes basada en grafos de conocimiento; base para que gud-framework recuerde contexto de clientes entre sesiones.

## Para tener en el radar

- **anthropics/financial-services** (+9, Python) — Referencia oficial de Anthropic para servicios financieros; patrones de prompts y arquitectura para verticales de consultoría.
- **chopratejas/headroom** (+117, Python) — Compresión de outputs de herramientas y RAG; reduce el tamaño del contexto en pipelines largos de análisis de cliente.
- **Panniantong/Agent-Reach** (+6, Python) — Da a los agentes acceso a la web en tiempo real; útil para enriquecer diagnósticos con datos públicos de mercado.

## Tendencias detectadas

- **Explosión de skills/plataformas de agentes**: La mayoría del trending es infraestructura para empaquetar y distribuir agentes (astrid, multica, agent-skills). gud-framework debe alinearse con este ecosistema de skills para no quedar aislado.
- **Reducción de costos LLM como producto**: rtk y headroom apuntan a que la eficiencia de tokens es ya un diferenciador. Integrar compresión de contexto en pipelines de consultoría es urgente.
- **Presentaciones y output visual desde agentes**: OfficeCLI + hyperframes + Understand-Anything muestran convergencia hacia generación automática de entregables visuales desde código.
