# GUD Scout - 2026-05-25

## Hallazgos principales

- **presenton/presenton** (+103, TypeScript) — INSTALAR — Generador de presentaciones IA open-source con API REST; ideal para automatizar entregables de consultoría (propuestas, informes, decks de cierre).

- **hugohe3/ppt-master** (+87, Python) — INSTALAR — Convierte cualquier documento en PPTX editable nativo usando IA; encaja directo en un pipeline doc→deck para clientes.

- **anthropics/knowledge-work-plugins** (+88, Python) — INSTALAR — Plugins oficiales Anthropic para trabajo de conocimiento; base lista para extender gud-framework con capacidades de síntesis y research.

- **anthropics/claude-plugins-official** (+250, Python) — INSTALAR — Directorio oficial de plugins Claude de alta calidad; referencia imprescindible para decidir qué integrar en el stack de automatización.

- **withcoral/coral** (+39, TypeScript) — VIGILAR — Interfaz SQL unificada sobre APIs, archivos y fuentes en vivo; útil para crear pipelines de datos de clientes sin ETL manual.

- **multica-ai/multica** (+93, TypeScript) — VIGILAR — Plataforma open-source de agentes gestionados; permite pasar agentes de prototipo a producción con observabilidad, apto para orquestar flujos de consultoría.

- **teng-lin/notebooklm-py** (+38, Python) — VIGILAR — API Python no oficial para Google NotebookLM con skill para agentes; puente hacia el ecosistema Google Workspace desde gud-framework.

- **virattt/dexter** (+42, TypeScript) — VIGILAR — Agente autónomo de investigación financiera profunda; modelo de referencia para construir un módulo de due diligence de clientes.

## Para tener en el radar

- **addyosmani/agent-skills** (+43, Shell) — Skills de producción para agentes; colección curada compatible con Claude Code que puede enriquecer el toolkit de gud-framework.

## Tendencias detectadas

- **Explosión de herramientas PPTX/presentaciones con IA**: dos repos independientes (presenton, ppt-master) llegan al top simultáneamente — el mercado valida este caso de uso para consultoría.
- **Plugins oficiales de Anthropic para work knowledge**: Anthropic está apostando por verticales de conocimiento (financial-services, knowledge-work-plugins), alineado con el modelo de gud-framework.
- **Convergencia MCP + skills**: los repos de skills (addyosmani, ComposioHQ, thananon) están ganando tracción como capa de capacidades modulares, mismo patrón que gud necesita para escalar servicios.
