# GUD Scout - 2026-07-30

## Hallazgos principales

- **virgiliojr94/book-to-skill** (4⭐, Python) — INSTALAR — Convierte cualquier PDF técnico en un skill de Claude Code; permite empaquetar metodología de consultoría como skill reutilizable al instante.
- **diegosouzapw/OmniRoute** (5⭐, TypeScript) — INSTALAR — Gateway MIT gratuito que unifica todos los endpoints de IA bajo una sola llamada; reduce fricción al conectar múltiples modelos en pipelines de GUD.
- **EverMind-AI/EverOS** (1⭐, Python) — INSTALAR — Capa de memoria portable y persistente para cualquier agente IA; crítico para mantener contexto de proyectos de consultoría entre sesiones.
- **andrewyng/openworker** (2⭐, Python) — VIGILAR — Framework de agentes de Andrew Ng orientado a workers autónomos; arquitectura relevante para los agentes de automatización de GUD.
- **heygen-com/hyperframes** (2⭐, TypeScript) — VIGILAR — Escribe HTML, renderiza video, hecho para agentes; abre la puerta a generar presentaciones de cliente como video directamente desde un agente.
- **iOfficeAI/OfficeCLI** (1⭐, ?) — VIGILAR — Suite Office AI-first orientada a CLI; potencial para generar PPTX/docs desde pipelines automatizados sin interfaz gráfica.
- **microsoft/agent-governance-toolkit** (1⭐, Python) — VIGILAR — Governance y policy enforcement para agentes IA enterprise; útil para auditorías y cumplimiento en proyectos de consultoría enterprise.
- **OpenNSWM-Lab/FAROS** (2⭐, Python) — VIGILAR — Runtime de auto-investigación conducido por blueprints; podría automatizar la fase de diagnóstico en proyectos de consultoría.
- **browser-use/browser-harness** (1⭐, Python) — VIGILAR — Harness de browser auto-healing para agentes; ideal para integraciones con portales de cliente y scraping de datos.

- **NVIDIA/SkillSpector** — Scanner de seguridad para skills de agentes IA; relevante si GUD distribuye skills propios.

## Tendencias detectadas

- **Skills de Claude como unidad de distribución**: book-to-skill, emilkowalski/skills y nature-skills muestran un patrón claro — el ecosistema está empaquetando conocimiento especializado como skills instalables, no como prompts ad-hoc.
- **Gateways IA unificados**: OmniRoute refleja demanda de abstracción multi-modelo; el mercado quiere una sola interfaz para Claude, GPT, Gemini.
- **Video generado por agentes**: hyperframes y bradautomates/claude-video indican que la generación de presentaciones multimedia vía agente está madurando como caso de uso real.
