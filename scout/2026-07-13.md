# GUD Scout - 2026-07-13

## Hallazgos principales

- **anthropics/knowledge-work-plugins** (1★, Python) — INSTALAR — Plugins oficiales de Anthropic para trabajo del conocimiento: plantillas, gestión de documentos y flujos estructurados que encajan directamente en pipelines de consultoría con Claude.

- **oomol-lab/open-connector** (1★, TypeScript) — VIGILAR — Gateway de autenticación open-source que conecta 1000+ productos SaaS; elimina la fricción de integraciones con Google Workspace, CRMs y herramientas de cliente en un solo punto.

- **DeusData/codebase-memory-mcp** (2★, C) — VIGILAR — Servidor MCP de inteligencia de código de alto rendimiento; patrón reutilizable para construir servidores MCP propios que indexen y consulten documentación de proyectos de consultoría.

- **multica-ai/multica** (1★, Go) — VIGILAR — Plataforma open-source de agentes gestionados que convierte código en bots de automatización; candidato natural para orquestar los agentes del gud-framework sin infraestructura propia.

- **ldbinac/smart_table** (1★, Vue) — INSPIRACION — Tabla multidimensional tipo Airtable con vistas kanban, agrupación y filtros; referencia de UI para portales de cliente con seguimiento de OKRs y proyectos.

- **microsoft/SkillOpt** (1★) — VIGILAR — Optimizador de skills en espacio de texto que entrena prompts reutilizables; técnica aplicable para mejorar y estandarizar las skills del gud-framework.

- **zosmaai/pi-llm-wiki** (1★, TypeScript) — VIGILAR — Base de conocimiento auto-mantenida compatible con Obsidian; útil como capa de memoria persistente para consultores en proyectos recurrentes.

- **Mininglamp-OSS/octo-cli** (1★) — VIGILAR — CLI metadata-driven para bots de agentes IA con 48 operaciones predefinidas; modelo de arquitectura para el CLI de gud-framework.

- **vercel-labs/agent-browser** (1★, Rust) — VIGILAR — CLI de automatización de navegador para agentes IA; permite a los agentes de gud-framework recopilar datos de portales web de clientes sin API.

- **radixark/miles** (1★, Python) — INSPIRACION — Agente de aprendizaje por refuerzo orientado a empresa; enfoque de RL para optimizar flujos de consultoría repetitivos a largo plazo.

## Para tener en el radar

- **hugoii/llm-agent-audit** — Trazabilidad de autorizaciones de herramientas en agentes LLM; crítico para auditorías de cumplimiento en proyectos de consultoría regulada.
- **multica-ai/multica** — Plataforma de agentes gestionados; alternativa a construir orquestación propia.
- **OpenHands/agent-canvas** — Canvas visual de agentes IA; útil para demos de capacidades de gud-framework a clientes.

## Tendencias detectadas

- **Explosión de servidores MCP**: múltiples repos emergen con servidores MCP especializados (código, memoria, conectores); el ecosistema MCP madura rápidamente como capa de integración estándar.
- **Plataformas de agentes gestionados**: multica y similares señalan que el mercado se mueve hacia hosting de agentes como servicio, no solo código de agente.
- **Skills y plugins de conocimiento**: Anthropic publica plugins oficiales de knowledge work, indicando que el modelo de skills es el camino para automatización de consultoría.
- **CLI como interfaz primaria de agentes**: octo-cli, agent-browser y otros CLI refuerzan el patrón de herramientas de línea de comandos como orquestadores de agentes.
