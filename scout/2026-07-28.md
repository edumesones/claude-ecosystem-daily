# GUD Scout - 2026-07-28

## Hallazgos principales

- **hugohe3/ppt-master** (+3⭐, Python) — INSTALAR — IA convierte documentos o temas en PowerPoint real y nativo; perfecto para automatizar entregables de consultoría.
- **oomol-lab/open-connector** (+5⭐, TypeScript) — INSTALAR — Gateway de auth abierto que conecta 1000+ SaaS; habilita integraciones con Google Workspace, CRM y herramientas de cliente sin fricción.
- **1weiho/open-slide** (+1⭐, TypeScript) — VIGILAR — Framework de slides construido para agentes; permite que gud-framework genere presentaciones directamente desde un pipeline.
- **iOfficeAI/OfficeCLI** (+14⭐, C#) — VIGILAR — Suite Office completa desde CLI; abre la puerta a generar y editar documentos Word/Excel/PowerPoint de forma programática.
- **stablyai/orca** (+3⭐, TypeScript) — VIGILAR — ADE para flotas de agentes paralelos; útil para orquestar múltiples tareas de consultoría simultáneas.
- **HKUDS/CLI-Anything** (+5⭐, Python) — VIGILAR — Convierte cualquier software existente en "agent-native"; sirve para envolver herramientas de consultoría legacy.

## Para tener en el radar

- **andrewyng/openworker** (+7⭐, Python) — Framework de workers de Andrew Ng; puede definir el patrón de referencia para agents workers en gud.
- **alibaba/open-code-review** (+4⭐, Go) — Revisión automática open-source validada a escala Alibaba; patrón adaptable para revisión de entregables y propuestas.
- **imraywang/wewrite** (+1⭐, Python) — Pipeline completo de contenido (tendencias → borrador → publicación); inspiración para pipelines de reportes automatizados.

## Tendencias detectadas

- **Presentaciones por IA en auge**: ppt-master y open-slide apuntan a que la generación de slides se vuelve un commodity — gud debería tener esta capa lista.
- **Skills/plugins como unidad de distribución**: vercel-labs/skills, MengTo/Skills, anbeime/skill indican que los skills de agentes se están estandarizando como apps; oportunidad para publicar skills de gud en marketplaces.
- **Gateways unificados de integración**: OmniRoute y open-connector consolidan el acceso a múltiples SaaS bajo un solo endpoint, patrón clave para portales de cliente.
