- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (5⭐, C#) — INSTALAR — Suite Office CLI orientada a IA: automatiza Word, Excel y PowerPoint desde terminal, ideal para generar entregables de consultoría sin abrir el escritorio.

- **[markdown-viewer/markdown-viewer-extension](https://github.com/markdown-viewer/markdown-viewer-extension)** (1⭐) — INSTALAR — Convierte Markdown con Mermaid y tablas a Word perfecto en un clic; cierra el gap entre outputs de agentes y documentos que el cliente puede abrir.

- **[phuryn/pm-skills](https://github.com/phuryn/pm-skills)** (1⭐) — INSTALAR — Marketplace con 100+ skills agenticas de PM (OKRs, roadmaps, gestión de proyectos); se instalan directo en Claude Code como comandos slash.

- **[microsoft/flint-chart](https://github.com/microsoft/flint-chart)** (3⭐, TypeScript) — VIGILAR — Lenguaje de visualización que permite a IA crear y editar gráficos de forma programática; útil para dashboards de cliente generados por agentes.

- **[tt-a1i/archify](https://github.com/tt-a1i/archify)** (1⭐, JavaScript) — INSTALAR — Skill de agente que genera diagramas de arquitectura bonitos; convierte cualquier descripción en un diagrama listo para presentación.

- **[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)** (2⭐, TypeScript) — VIGILAR — CLI que escribe y mantiene documentación de agentes automáticamente; base para un wiki vivo de los procesos de consultoría del cliente.

- **[gastownhall/gastown](https://github.com/gastownhall/gastown)** (2⭐, Go) — VIGILAR — Gestor de workspace multi-agente en terminal; orquesta varios agentes en paralelo, modelo interesante para pipelines de análisis de consultoría.

- **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** (1⭐, Python) — INSTALAR — Skill que investiga cualquier tema en múltiples fuentes de los últimos 30 días; automatiza la fase de desk research de un proyecto de consultoría.

- **[DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** (2⭐, C) — VIGILAR — Servidor MCP de memoria de código de alto rendimiento; patrón aplicable para que gud-framework recuerde contexto entre sesiones de cliente.

## Tendencias detectadas

- **Explosión de skills instalables**: la mayoría de repos nuevos son skills/plugins para Claude Code, no proyectos standalone — el ecosistema se está fragmentando en microherramientas instalables.
- **Office CLI como nuevo frente**: iOfficeAI apunta a automatizar el stack ofimático directamente desde agentes, sin APIs de Google ni Microsoft 365 — más simple, menos dependencias.
- **Documentación autogenerada**: openwiki y similares sugieren que la documentación de procesos pasará a ser un output automático de los agentes, no una tarea manual.
