# GUD Scout - 2026-07-08

## Hallazgos principales

- **iOfficeAI/OfficeCLI** (+5, C#) — INSTALAR — Suite Office completa diseñada para agentes IA; genera y manipula documentos directamente desde flujos automatizados, eliminando dependencia de interfaces gráficas para entregables de consultoría.

- **ComPDFKit/compdf-self-hosted** (+3, TypeScript) — INSTALAR — Solución self-hosted para editar, convertir y transformar PDFs; clave para automatizar la generación de reportes finales y propuestas para clientes sin depender de servicios externos.

- **oomol-lab/open-connector** (+2, TypeScript) — INSTALAR — Gateway de autenticación open-source que conecta 1000+ productos SaaS; puede unificar el acceso a herramientas de clientes (Drive, CRM, Slack) en un solo punto de integración para gud-framework.

- **coreyhaines31/marketingskills** (+2, JavaScript) — INSTALAR — Skills de marketing listos para Claude Code y agentes IA; aceleran la creación de materiales de presentación y comunicación con clientes.

- **langchain-ai/openwiki** (+15, TypeScript) — VIGILAR — CLI que escribe y mantiene documentación de agentes automáticamente; patrón aplicable para auto-documentar los workflows de consultoría generados por gud-framework.

- **microsoft/SkillOpt** (+3, Python) — VIGILAR — Optimizador de texto que entrena skills reutilizables; permite refinar y mejorar los prompts/skills del framework con retroalimentación iterativa.

- **gastownhall/gastown** (+3, Go) — VIGILAR — Gestor de workspace multi-agente en terminal; modelo de orquestación útil para coordinar agentes especializados (análisis, redacción, presentación) en un proyecto de consultoría.

- **mvanhorn/last30days-skill** (+3, Python) — VIGILAR — Skill de investigación que rastrea tendencias recientes en cualquier tema; útil para la fase de research de mercado en propuestas de consultoría.

## Para tener en el radar

- **alibaba/page-agent** (+5, TypeScript) — Agente GUI in-page para controlar interfaces web; puede automatizar la extracción de datos desde portales de clientes sin API.
- **vercel-labs/agent-browser** (+2, Rust) — CLI de automatización de navegador para agentes; complementa page-agent para flujos que requieren interacción con aplicaciones web.
- **MadsLorentzen/ai-job-search** (+10, TypeScript) — Framework de automatización de workflows con Claude; su arquitectura (inputs estructurados → análisis → output formateado) es directamente inspiradora para pipelines de consultoría.
- **teamchong/pxpipe** (+4, TypeScript) — Pipeline de datos TypeScript; revisar si tiene conectores útiles para integrar fuentes de datos de clientes.

## Tendencias detectadas

- **Skills como producto**: Múltiples repos publican skills reutilizables para agentes (kangjie-skill, marketingskills, nature-skills, dotnet/skills). El ecosistema de skills está madurando rápidamente — gud-framework debería publicar sus propios skills.
- **Office CLI para IA**: Emerge un patrón de herramientas de oficina diseñadas específicamente para ser consumidas por agentes (iOfficeAI/OfficeCLI), no por humanos. Cambia el paradigma de generación de entregables.
- **Multi-agente como estándar**: gastown, herdr, orca, tutti-os apuntan a que la coordinación de flotas de agentes es el siguiente paso en productividad — directamente relevante para escalar consultoría automatizada.
