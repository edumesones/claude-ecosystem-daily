# GUD Scout - 2026-06-25

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+10, Python) — INSTALAR — Genera PowerPoint reales y editables con IA desde cualquier prompt; automatiza entregables de consultoría sin tocar PowerPoint manualmente.

- **[googleworkspace/cli](https://github.com/googleworkspace/cli)** (+9, Rust) — INSTALAR — CLI oficial de Google para Drive, Docs y Sheets desde terminal; pieza clave para automatizar el flujo de trabajo con clientes en Workspace.

- **[chopratejas/headroom](https://github.com/chopratejas/headroom)** (+15, Python) — INSTALAR — Comprime outputs de herramientas, logs y chunks de RAG; reduce consumo de contexto en agentes que procesan muchos documentos de cliente.

- **[anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)** (+6, Python) — INSTALAR — Directorio oficial de plugins de Claude mantenido por Anthropic; punto de entrada para encontrar integraciones certificadas para gud-framework.

- **[DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** (+21, C) — VIGILAR — Servidor MCP de memoria de código de alto rendimiento; patrón para construir memoria contextual persistente de proyectos por cliente.

- **[zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides)** (+2, JavaScript) — VIGILAR — Crea slides profesionales con código en el navegador; alternativa web a ppt-master para presentaciones interactivas en portales de cliente.

- **[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)** (+6, TypeScript) — VIGILAR — Escribe HTML, renderiza video; pensado para agentes que producen presentaciones dinámicas en video para clientes.

- **[multica-ai/multica](https://github.com/multica-ai/multica)** (+3, Go) — VIGILAR — Plataforma open-source de agentes gestionados; patrón de orquestación multi-agente aplicable a la arquitectura de gud-framework.

- **[rtk-ai/rtk](https://github.com/rtk-ai/rtk)** (+7, Rust) — INSTALAR — Proxy CLI que reduce consumo de tokens LLM un 60%; reduce costos operativos de agentes de consultoría en producción.

## Para tener en el radar

- **[EverMind-AI/EverOS](https://github.com/EverMind-AI/EverOS)** — Memoria auto-evolutiva cross-agente y cross-plataforma; relevante para contexto persistente de clientes entre sesiones.
- **[alibaba/page-agent](https://github.com/alibaba/page-agent)** — Agente GUI en JavaScript que controla interfaces web; automatizar CRMs y portales de terceros sin API.
- **[BuilderIO/agent-native](https://github.com/BuilderIO/agent-native)** — Framework para apps diseñadas desde el inicio para agentes; inspiración para rediseñar el portal de cliente de gud.

## Tendencias detectadas

- **Compresión y memoria de contexto en auge**: tres proyectos independientes (headroom, EverOS, codebase-memory-mcp) atacan el mismo cuello de botella — agentes con mucho contexto — señal de que el problema es real y prioritario.
- **Google Workspace se vuelve CLI-first**: el CLI oficial de Google consolida acceso a toda la suite desde agentes; el ecosistema se mueve hacia automatización headless de Workspace.
- **Generación de presentaciones con IA madura**: ppt-master y frontend-slides indican que la generación de entregables visuales ya es un caso de uso resuelto, no experimental.
