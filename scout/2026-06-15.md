# GUD Scout - 2026-06-15

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+11, Python) — INSTALAR — Genera PPTX reales y editables con IA desde cualquier prompt; candidato directo para el módulo de entregables de consultoría.

- **[zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides)** (+8) — INSTALAR — Crea slides web con código, pensado para agentes; útil para presentaciones de cliente sin depender de PowerPoint.

- **[anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)** (+11, Python) — INSTALAR — Repositorio oficial de Anthropic con plugins para trabajo del conocimiento; base sólida para extender el harness de gud-framework.

- **[Agents365-ai/drawio-skill](https://github.com/Agents365-ai/drawio-skill)** (+16, Python) — INSTALAR — Genera diagramas draw.io desde lenguaje natural; cubre la creación de mapas de proceso y arquitecturas en entregables de consultoría.

- **[teng-lin/notebooklm-py](https://github.com/teng-lin/notebooklm-py)** (+9, Python) — VIGILAR — API Python no oficial de Google NotebookLM con skill incluida; conecta corpus documental de clientes con agentes IA.

- **[corsairdev/corsair](https://github.com/corsairdev/corsair)** (+15, TypeScript) — VIGILAR — Capa de integración para agentes (estilo middleware); patrón útil para conectar gud-framework con servicios externos (CRM, Drive, Slack).

- **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** (+51, Python) — VIGILAR — Skill que investiga cualquier tema en Reddit/HN de los últimos 30 días; aplicable a análisis de mercado y due diligence para clientes.

- **[sickn33/antigravity-awesome-skills](https://github.com/sickn33/antigravity-awesome-skills)** (+7) — VIGILAR — Biblioteca de 1,400+ skills instalables para agentes; revisar si hay skills de Google Workspace, CRM o reportes.

- **[GoogleCloudPlatform/knowledge-catalog](https://github.com/GoogleCloudPlatform/knowledge-catalog)** (+37, Python) — VIGILAR — Catálogo de conocimiento en Google Cloud; relevante si los clientes viven en GCP/Drive.

- **[Ar9av/obsidian-wiki](https://github.com/Ar9av/obsidian-wiki)** — Agentes que construyen y mantienen wikis; patrón para gestión del conocimiento de proyectos de consultoría.

- **[Thysrael/Horizon](https://github.com/Thysrael/Horizon)** (+22, Python) — Radar de noticias con IA que genera informes diarios; patrón directo para briefings de cliente automatizados.
- **[kenn-io/agentsview](https://github.com/kenn-io/agentsview)** (+24, Go) — Analytics local de sesiones de agentes; útil para monitorear el uso del harness por los consultores.

## Tendencias detectadas

- **Explosión de skills instalables**: múltiples repos esta semana apuntan a skills como unidad modular de capacidad; gud-framework debería adoptar este patrón para distribuir automatizaciones.
- **Presentaciones y diagramas con agentes**: ppt-master, frontend-slides, archify y drawio-skill confirman demanda alta de generación de entregables visuales desde IA — área de alto valor para consultoría.
- **Memoria persistente para agentes**: agentmemory y LycheeMem (+10) muestran madurez creciente; habilitar memoria de proyecto en gud-framework se convierte en prioridad.
- **Google Workspace en radar**: notebooklm-py y knowledge-catalog (Google Cloud) sugieren que el ecosistema IA está convergiendo hacia integración nativa con Google.
