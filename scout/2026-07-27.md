# GUD Scout - 2026-07-27

## Hallazgos principales

- **[chuspeeism/dashi-ppt-skill](https://github.com/chuspeeism/dashi-ppt-skill)** (1★, JS) — INSTALAR — Skill que genera PPT editables en el navegador desde agentes IA; directamente aplicable para automatizar entregables de consultoría.

- **[virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)** (2★, Python) — INSTALAR — Convierte cualquier PDF técnico en un skill de Claude; útil para cargar metodologías y frameworks propios de GUD como contexto reutilizable.

- **[blader/humanizer](https://github.com/blader/humanizer)** (2★, Python) — INSTALAR — Skill que elimina señales de escritura IA en textos; esencial para propuestas y comunicaciones con clientes que deben sonar naturales.

- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (4★, C#) — VIGILAR — Suite Office completa vía CLI para agentes (Word, Excel, PPT); podría ser el puente faltante para automatizar documentos de consultoría sin Google Workspace.

- **[intercom/2x-skills](https://github.com/intercom/2x-skills)** (1★) — VIGILAR — Colección de skills genéricas de Claude publicada por Intercom; contiene patrones reutilizables para automatización de atención a clientes.

- **[corsairdev/corsair](https://github.com/corsairdev/corsair)** (2★, TS) — VIGILAR — Capa de integración entre agentes y servicios externos; arquitectura que puede simplificar pipelines de datos de GUD.

- **[DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** (2★, C) — VIGILAR — Servidor MCP de memoria de alto rendimiento; útil para mantener contexto acumulado de proyectos de clientes entre sesiones.

- **[baidu/Unlimited-OCR](https://github.com/baidu/Unlimited-OCR)** (2★, Python) — VIGILAR — OCR one-shot sin límites para digitalizar contratos y documentos de clientes antes de procesarlos con agentes.

## Tendencias detectadas

- **Explosión de skills para generación de presentaciones**: dashi-ppt-skill y hyperframes apuntan a que PPT/video desde IA es el próximo entregable estándar en consultoría.
- **Madurez del ecosistema de skills**: Intercom y Vercel publicando colecciones oficiales indica que las skills de Claude se están convirtiendo en infraestructura de producto, no solo experimentos.
- **Humanización como capa obligatoria**: humanizer aparece como necesidad específica, señal de que los clientes ya distinguen texto IA del humano.
