# GUD Scout - 2026-06-27

## Hallazgos principales

- **hugohe3/ppt-master** (+14, Python) — INSTALAR — Genera PowerPoint real y editable con IA desde cualquier prompt; solución directa para automatizar decks de propuestas y reportes de consultoría.

- **googleworkspace/cli** (+5, Rust) — INSTALAR — CLI oficial para Drive, Docs, Sheets y Calendar desde terminal; permite integrar Google Workspace en pipelines automatizados de gud-framework sin usar la UI.

- **lewislulu/html-ppt-skill** (+5, HTML) — VIGILAR — AgentSkill con 24 temas y 31 layouts para generar presentaciones HTML desde Claude; complementa ppt-master con salida web inmediata.

- **stablyai/orca** (+18, TypeScript) — VIGILAR — ADE para orquestar flotas de agentes paralelos; arquitectura clave si gud-framework necesita escalar múltiples tareas de consultoría simultáneas.

- **Tencent/WeKnora** (+7, Go) — VIGILAR — Convierte documentos raw en conocimiento estructurado con LLM; útil para ingerir documentación de clientes y generar bases de conocimiento.

- **anbeime/skill** (+6, Python) — VIGILAR — Tienda de skills con procesamiento de docs, creación de contenido y automatización de workflows; repositorio para ampliar capacidades del agente.

- **Agents365-ai/drawio-skill** (+4, Python) — VIGILAR — Genera diagramas draw.io desde lenguaje natural; ideal para automatizar diagramas de procesos en entregables de consultoría.

- **anthropics/financial-services** (+4, Python) — VIGILAR — Templates oficiales de Anthropic para servicios financieros; modelo de referencia para análisis financiero automatizado en propuestas.

- **heygen-com/hyperframes** (+7, TypeScript) — VIGILAR — Renderiza video desde HTML para agentes; abre la puerta a generar demos y walkthrough de proyectos de forma automatizada.

- **EverMind-AI/EverOS** (+6, Python) — VIGILAR — Memoria auto-evolutiva entre sesiones y plataformas; permite que el agente recuerde contexto de cliente entre conversaciones.

## Tendencias detectadas

- **Explosión de skills para agentes**: múltiples repos publicando AgentSkills listos para instalar (presentaciones, diagramas, investigación, contenido). El ecosistema se está modularizando.
- **Presentaciones en todos los formatos**: PPTX (ppt-master), HTML interactivo (html-ppt-skill), video (hyperframes, OpenMontage). La generación de entregables visuales es el tema del momento.
- **Google Workspace se integra con CLI/agentes**: googleworkspace/cli oficializa la automatización del stack más usado en consultoría.
- **Orquestación multi-agente madura**: orca, nasiko y herdr apuntan a gestión de flotas de agentes, no agentes individuales.
