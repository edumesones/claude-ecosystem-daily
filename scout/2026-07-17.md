# GUD Scout - 2026-07-17

## Hallazgos principales

- **[crazyykhllc-bit/CyberPPT](https://github.com/crazyykhllc-bit/CyberPPT)** (2★, Python) — INSTALAR — Skill de Codex que genera PowerPoint estilo consultoría con estructura SCR/pirámide; ideal para automatizar entregables de cliente en GUD sin tocar Keynote.

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (4★, Python) — INSTALAR — IA genera un PPT real y editable desde cualquier fuente de texto; encaja directo en el pipeline de propuestas y reportes de GUD.

- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (20★ semanal, C#) — VIGILAR — Suite Office completa manejable por CLI; permite automatizar Word/Excel/PPT desde agentes sin depender de Google Workspace.

- **[oomol-lab/open-connector](https://github.com/oomol-lab/open-connector)** (2★, TypeScript) — VIGILAR — Gateway de autenticación open-source para 1000+ SaaS; simplifica conectar CRM, Drive y herramientas de cliente en un solo punto de integración.

- **[stablyai/orca](https://github.com/stablyai/orca)** (4★, TypeScript) — VIGILAR — ADE para orquestar flotas de agentes paralelos; referencia de arquitectura para el sistema multi-agente de GUD.

- **[EverMind-AI/EverOS](https://github.com/EverMind-AI/EverOS)** (3★, Python) — VIGILAR — Capa de memoria portátil para agentes IA (local + nube); permite que los agentes de GUD recuerden contexto del cliente entre sesiones.

## Tendencias detectadas

- **Explosión de skills de PPT/Office con IA**: dos repos independientes de generación de PowerPoint aparecieron simultáneamente, señal de demanda alta en automatización de presentaciones.
- **Skills como unidad de distribución**: marketing, ciberseguridad, consultoría, contenido — todo se empaqueta como skill de Claude Code; GUD debería publicar sus propias skills.
- **Gateways SaaS como infraestructura común**: open-connector y OmniRoute apuntan a que la capa de integración se está comoditizando, reduce el costo de conectar herramientas de cliente.
