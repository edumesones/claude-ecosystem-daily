# GUD Scout - 2026-08-12

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+5, Python) — INSTALAR — Convierte documentos o temas en PowerPoint nativo con IA; encaja directamente en el flujo de generación de entregables de consultoría.

- **[corsairdev/corsair](https://github.com/corsairdev/corsair)** (+8, TypeScript) — VIGILAR — Capa de integración para agentes que conecta herramientas y APIs externas; útil para orquestar los flujos de automatización de gud-framework.

- **[stablyai/orca](https://github.com/stablyai/orca)** (+9, TypeScript) — VIGILAR — ADE (Agent Development Environment) para flotas de agentes paralelos; referente arquitectónico para escalar tareas de análisis en paralelo.

- **[melgarafael/DeskcommCRM](https://github.com/melgarafael/DeskcommCRM)** (+3, TypeScript) — VIGILAR — CRM open-source con IA y lenguaje natural; base reutilizable para un portal de cliente o gestión de cuentas en gud.

- **[firecrawl/anydoc](https://github.com/firecrawl/anydoc)** (+6, Rust) — VIGILAR — Parser universal de documentos (contratos, reportes, PDFs); habilita la ingesta de materiales de cliente sin fricción.

- **[superdesigndev/tools-registry](https://github.com/superdesigndev/tools-registry)** (+3, Python) — VIGILAR — Vault compartido de skills y secrets para equipos y agentes; patrón directo para distribuir skills de gud entre varios consultores.

- **[vercel-labs/skills](https://github.com/vercel-labs/skills)** (+2, TypeScript) — INSTALAR — CLI `npx skills` para gestionar e instalar skills de agentes; simplifica el onboarding de nuevas capacidades en el ecosistema.

## Para tener en el radar

- **[HKUDS/OpenOPC](https://github.com/HKUDS/OpenOPC)** — "Build Your Personal AI-Native Company"; inspiración directa para modelar gud como empresa operada por agentes.
- **[multica-ai/multica](https://github.com/multica-ai/multica)** — Plataforma open-source de agentes administrados; alternativa a construir el runtime de gud desde cero.
- **[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)** — CLI que escribe y mantiene wikis de agentes automáticamente; útil para documentación interna de gud.
- **[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)** — Skills de marketing para Claude Code; reutilizable para propuestas y comunicación con clientes.

## Tendencias detectadas

- Proliferación de **capas de integración para agentes** (corsair, orca, multica): el mercado converge hacia runtimes que orquestan flotas en lugar de agentes únicos.
- **Skills como unidad de distribución de conocimiento**: book-to-skill, tools-registry, vercel-labs/skills apuntan a un ecosistema donde el conocimiento experto se empaqueta y comparte como skill instalable.
- **Generación de documentos Office con IA** sigue ganando tracción (ppt-master lleva 2 días consecutivos en tendencia): el entregable en PowerPoint ya es demanda concreta, no solo aspiration.
