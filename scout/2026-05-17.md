## Tendencias detectadas

- **Explosión de skills para Claude Code**: múltiples repos de skills especializados (PPT, marketing, ciencia, ingeniería) — el ecosistema se fragmenta en verticales, oportunidad para un skill bundle de consultoría.
- **MCP como capa de integración estándar**: n8n-mcp confirma que MCP se usa para conectar cualquier herramienta existente con Claude; gud-framework debería prioritizar servidores MCP propios.
- **Presentaciones IA en auge**: dos repos independientes de generación de slides el mismo día señalan demanda real de entregables automatizados.
