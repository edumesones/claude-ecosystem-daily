# GUD Scout - 2026-08-03

## Hallazgos principales

- **WuKongOpenSource/Wukong-AICRM** (1★, Java) — INSTALAR — CRM open-source con IA integrada, alternativa directa a Salesforce con asistente tipo ChatGPT para gestión de clientes; listo para desplegar en flujos de consultoría.

- **firecrawl/pdf-inspector** (10★, Rust) — VIGILAR — Inspector de PDFs lider del ranking general; clave para procesar propuestas, contratos y entregables de consultoría de forma programática.

- **iOfficeAI/OfficeCLI** (5★/7d, C#) — VIGILAR — CLI completa para suite Office (Word/Excel/PPT) desde terminal; permite automatizar generación de presentaciones y reportes sin GUI.

- **diegosouzapw/OmniRoute** (14★/7d, TypeScript) — VIGILAR — Gateway unificado MIT para múltiples LLMs con un solo endpoint; reduce vendor lock-in y costo de integración para gud-framework.

- **yc-software/qm** (6★, TypeScript) — VIGILAR — Harness multiplayer para coordinar agentes de trabajo en equipo; patrón directo para proyectos de consultoría multi-agente.

- **Open-Curiosity/gini-agent** (1★, TypeScript) — VIGILAR — Agente con memoria persistente que aprende; útil para retener contexto de cliente entre sesiones.

- **langchain-ai/openwiki** (4★/7d, TypeScript) — VIGILAR — CLI que escribe y mantiene wikis automáticamente; candidato para documentación viva de proyectos de consultoría.

## Para tener en el radar

- **ascending-llc/jarvis-registry** (1★, Python) — Registro de agentes IA que conecta copilots a sistemas de negocio; base potencial para marketplace de herramientas gud.

- **andrewyng/openworker** (2★, Python) — Framework de Andrew Ng para agentes de trabajo autónomo; observar si publica documentación completa.

- **herdrdev/herdr** (12★/7d, Rust) — Multiplexor de agentes en terminal; referencia de arquitectura para orquestación ligera.

- **microsoft/SkillOpt** (1★, Python) — Optimizador de skills en espacio de texto para agentes; puede mejorar calidad de prompts en gud-skills.

## Tendencias detectadas

- **Harness multiplayer**: varios proyectos (qm, herdr) apuestan por coordinar múltiples agentes de IA para trabajo en equipo, no solo uso individual.
- **CRM con IA nativa**: Wukong-AICRM confirma que los CRM open-source están integrando IA desde el diseño base, no como add-on.
- **Gateways unificados de LLM**: OmniRoute y OmniCodex apuntan a la necesidad de abstraer proveedores; patrón a adoptar en gud-framework para no atarse a un modelo.
