# GUD Scout - 2026-08-08

## Hallazgos principales

- **[hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)** (+3 estrellas, Python) — INSTALAR — Convierte documentos o temas en presentaciones PowerPoint nativas con IA; encaja directo en el pipeline de entregables de consultoría.

- **[firecrawl/pdf-inspector](https://github.com/firecrawl/pdf-inspector)** (+3 estrellas, Rust) — INSTALAR — Inspector de PDFs del equipo de Firecrawl; útil para extraer datos de documentos cliente antes de procesarlos con agentes.

- **[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)** (+7 estrellas 7d, C#) — INSTALAR — Suite Office completa por CLI; permite automatizar Word/Excel/PPT desde pipelines sin abrir apps de escritorio.

- **[vercel-labs/skills](https://github.com/vercel-labs/skills)** (+1 estrella, TypeScript) — VIGILAR — Herramienta open de gestión de skills para agentes (`npx skills`); podría ser la base para empaquetar y distribuir skills propios de gud.

- **[magicrew/doc7](https://github.com/magicrew/doc7)** (+2 estrellas, Go) — VIGILAR — Transforma documentos a Markdown conservando layout visual; ideal para ingestar briefs y propuestas de cliente.

- **[diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute)** (+14 estrellas 7d, TypeScript) — VIGILAR — Gateway MIT gratuito que unifica múltiples modelos en un endpoint; reduce acoplamiento al proveedor en pipelines de consultoría.

- **[assafkip/kipi-system](https://github.com/assafkip/kipi-system)** (+1 estrella, Python) — VIGILAR — "Tu cerebro IA externalizado" con memoria persistente; arquitectura inspiradora para el CRM de contexto de cliente en gud.

- **[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)** (+2 estrellas, TypeScript) — VIGILAR — Renderiza HTML como video para agentes; interesante para generar demos o resúmenes ejecutivos en video de entregables.

## Para tener en el radar

- **[tt-a1i/archify](https://github.com/tt-a1i/archify)** — Skill de agente para diagramas de arquitectura verificables; inspira un skill gud para diagramas de procesos de cliente.
- **[yc-software/qm](https://github.com/yc-software/qm)** — Harness multiplayer para agentes; patrón para coordinación de subagentes en proyectos de consultoría.
- **[TencentCloud/TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)** — Hub de memoria a nivel de equipo para agentes; referencia de arquitectura para memoria compartida en gud.
- **[tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)** — Grafo de inteligencia local para MCP; patrón de cómo conectar herramientas como servidor MCP.

## Tendencias detectadas

- **PPT/doc generation madura**: Múltiples repos apuntan a generación nativa de presentaciones desde IA, no solo HTML exportado.
- **Skills como unidad distribuible**: `vercel-labs/skills` y `emilkowalski/skills` señalan que el ecosistema converge hacia skills empaquetables con `npx`.
- **Gateway unificado de modelos**: OmniRoute y similares sugieren que los pipelines multi-modelo son el nuevo estándar, no depender de un solo proveedor.
